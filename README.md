## Собственный проект

Тема проекта: каталог космических объектов 

Главный класс: `SpaceObject`

Почему этот объект нужен программе: В этом объекте хранятся все основные универсальные переменные для корректного вывода данных

Какие данные хранит объект:

* `public string Name`-Название объекта
* `public string Type`-Тип объекта (планета, звезда, чёрная дыра и т.д.)
* `public string Location`-Местонахождение объекта относительно Земли
* `public double Light`-Расстояние от Земли до объекта (в световых годах) 
* `public string Mass`-Масса объекта (из-за слишком больших чисел пришлось оформить в виде строки)
* `public string Info`-Основная информация об объекте

Какие значения задаются через конструктор: Произвольные значения указанного типа данных 

Какие значения можно задавать автоматически: Значения всех параметров из конструктора
