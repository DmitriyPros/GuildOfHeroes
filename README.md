## Собственный проект

Тема проекта: каталог космических объектов 

Главный класс: `SpaceObject`

Почему этот объект нужен программе: В этом объекте хранятся все основные универсальные переменные для корректного вывода данных

Какие данные хранит объект:

* `public string Name`-Название объекта
* `public string Type`-Тип объекта (планета, звезда, чёрная дыра и т.д.)
* `public string Location`-Местонахождение объекта относительно Земли
* `public double Light`-Расстояние от Земли до объекта (в световых годах) 
* `public string Mass`-Масса объекта (из-за слишком больших чисел пришлось оформить в виде строки)
* `public string Info`-Основная информация об объекте

Какие значения задаются через конструктор: Произвольные значения указанного типа данных 

Какие значения можно задавать автоматически: Значения всех параметров из конструктора

## Практическая работа №2
### Поведение главного класса

Метод 1: `Zoom`
Что делает: Принимает числовое значение (приближение в световых годах); вычисляет, насколько объект приближен; проверяет, не уходит ли полученное значение в отрицательную сторону. С этим методом потом создаётся отдельная строка вывода.

Метод 2: `NalInfo`
Что делает: Принимает строковое значение и заменяет поле `Info`.

Метод 3: `Unik`
Что делает: Возвращает булево значение True/False, если объект является пульсаром или не является соответственно. Далее, через проверки для определённых объектов, метод определяет, уникален объект или нет. 

Почему эти действия относятся именно к этому классу: 
Класс `SpaceObject` является моделью реального космического объекта, поэтому он должен сам управлять своим состоянием. Метод `Zoom` напрямую изменяет характеристику объекта (его расстояние в зависимости от вводимого приближения), а `NalInfo` — его описательные данные. Метод `Unik` проверяет специфическое свойство конкретного объекта на основе его собственного поля `Type`. Инкапсуляция этих методов внутри класса гарантирует, что данные объекта (например, яркость) не будут изменены некорректно извне (например, ниже нуля), и вся логика работы с объектом находится в одном месте.
